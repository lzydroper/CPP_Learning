### 模板的一些实验

> 目前仅测试了一下模板声明和定义拆开写会怎么报错
> 主要为了研究模板的编译原理和流程
> 核心就是调用点编译期必须直接找到对应的定义，必须要实例化
> 总之就是只要那个模板参数不能完全确认，就不能当做函数/类
> 而是一个蓝图，调用点要么找到具体蓝图去生成代码，然后编译引用他
> 要么就找到个已经生成好的代码，直接引用他，一般是先找生成好的，所以为什么优先用重载函数
> 但如果找不到，就只看到声明，只能引用一个没有生成出代码的东西，链接期会报错`undefined reference`
> 但对于全特化不一样，他其实就是个完整定义，没有需要生成的内容，编译的时候不用找调用点，能直接编译，引用就能引用对，链接就不会报错
> 不过其他编译器可能过程不一样，但肯定会报错
